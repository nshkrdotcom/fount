# Future development register — 2026-09-24

## Scope decision

Feature development is frozen for the current stability pass. This register captures **all known unfinished feature behavior** found in the original [specification](spec_draft_implementation/README.md), [F/W/T coverage](FEATURES.md), [source-only gap list](KNOWN_GAPS.md), [wishlist](WISHLIST.md), and [current implementation record](STAGE2_STATUS_2026-09-24.md). It does not claim to predict future writer requests. The older handoff's instructions to implement every gap are superseded for this pass by the writer's freeze decision.

The current task is to verify, repair defects in, and report on **the behavior already implemented and tested**. A source route, a mocked test, and a live candidate are different levels of evidence. Never mark an original F/W/T case complete because it appears in this register. If a defect violates an existing documented contract, treat it as a stability blocker; if the missing behavior expands the contract, keep it here. No generated candidate changes the accepted draft without an explicit writer acceptance.
